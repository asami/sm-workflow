# Native independent-Human applicability

Date: 2026-10-11. Phase 5.2 adopted-policy migration; current inputs UNVERIFIED.

## R1 — Actual question and direction, not copied control certificates

Goal and Repository Human evidence selects owner, submitting participant,
question handle/run/slot, Required/completion routes, input/result types and
actual requesting-result/native assignment or conflict targets. Answers select
reference, worker and choice. ProvideResolution consumes literal conflict
identities/text; other choices do not consume unused resolutions.
Expected revision and model snapshot are omitted. Full question/result/Plan,
presentation, rationale, worktree text and generated-origin copies are not
encoded, compared or restored. Typed helpers emit current fields directly.
E1/E2 exercise production/current selection and unused metadata tolerance.

## R2 — Preserve independent admission at its actual boundary

Reader admits current issuer/purpose/lookup/worker/reference/target/occurrence
once using managed record-read permissions and the actual call clock. Without
this independent boundary a foreign direction or actor could be accepted.
The projector no longer duplicates native question/answer slot/type/model/route,
resolution coverage, path/OID/mode/array-count or uniqueness validation. Native
completion owns its actual result type/state/CAS, and actual materialization owns
path/content safety. No new verifier, receipt stamp or fallback is added.
E3 checks actual independently attested actors/targets/directions. E5 retains
literal newline paths and resolution contents. E6's duplicate producer/legacy
correlation requirements are retired. Native framework features are untouched.

## R3 — Current v7 only throughout producer and reader

Only current selected Human fields are read/written. All v1–v6 full-body adapters
and exact-key gates are removed. Unknown unused fields are ignored, never authority.
E4's compatibility matrix is retired. Historical rows are untouched; unsupported
old runs restart NEW with independently issued current evidence rather than
manufacturing consent. No old-format restoration guarantee is claimed.

## Remaining acceptance

Normal direct Operations and focused host specs require current runner evidence.
Other bounded legacy/internal/storage/CML migrations and connected review/release
remain. This document does not close Phase 5.2 or change history/counters/frames.
