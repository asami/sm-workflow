## R1 — Attest actual question and direction, not unchanged display or declarations

Goal ordered decisions and Repository native conflicts select actual component
instance, submitting participant, Workflow/instance/executable reference, issued
run/Continuation/revision, Required/completion routes and input/result/model
scope. The requesting-result reference resolves the actual originating decision.
Goal direction selects the native work assignment, Plan reference, Step/Phase/
generation and native base/candidate/check target. Repository direction selects
conflict frontier, native tips, ordered conflict IDs/paths/blob OIDs and mode.
These are real execution targets, not evidence that a declaration stayed unchanged.

The answer records its actual reference, Human participant and choice. A
ProvideResolution answer also records ordered conflict IDs and literal resolution
text, which is real actionable meaning. It does not store complete public
question/answer envelopes, full Plan/policy, conflict blob/worktree text copies,
diagnostic Workspace/evidence projections, presentation or explanatory rationale.
Original typed question/work meaning stays in Workflow storage. The attestation
neither truncates nor replaces it. It grants no command, closure, review acceptance
or additional repair allowance.

E1: `NativeHostHumanScopeSpec` compares both typed production helpers with legacy
semantic extraction and checks omitted copied bodies. E2 changes unused
question/Plan/context/presentation, conflict text and answer explanation projections;
actual attested direction remains selected. These passive codec/ingress examples
do not authorize malformed public requests: public decode and semantic admission
retain their own typed contracts.

submitting participant and actual Human worker/reference must match. Foreign

non-future occurrence, not a renewable expiry. Path and resolution text retain
their native literal semantics; valid path newlines are not forbidden as display
characters. Owning policy limits and actual materialization preconditions remain.

closing. Producer builds semantic scope once; the port does not regenerate it.

normal Reader consumes its storage-admitted scope without a second scope decoder;
the actual current target is admitted separately. No repeated issuer getter,
complete Binding equality or duplicate normal Human reference/worker check.
