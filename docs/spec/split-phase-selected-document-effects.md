runtime owns the executable, fixed repository root, exact complete argument

The trusted `SelectedPhaseDocumentProgram` projects the same selected document
material as Preview. It verifies the source's typed boundary and unfinished
Scope ownership, preserves completed rows and unrelated history, and refuses
occupied or inconsistent children. It preflights the full write set and creates
missing children without overwrite before atomically replacing the source's
managed sections. Each file is atomic; the multi-file write set is **not** a
crash-atomic transaction. A later observation recognizes matching already
applied children and resumes only missing work. A final source with missing
children is a conflict, not a reason to recreate independently deleted work.

The document lock coordinates cooperating writers only. It does not protect
against arbitrary editors ignoring that lock. No directory fsync or power-loss
durability is claimed. The observable lock file is not a Phase-document change;
Preview itself does not invoke this effect.
