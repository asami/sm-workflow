## Raw producer and reader

The producer serializes the declared fields without decoding its own output to
prove equality with the submitted record. The reader admits the declared nested
wire structure and types, then decodes once and resolves the selected address.
It does not re-encode data and compare a canonical JSON body. Context uses the
same nine-purpose input declarations as independent planning rows.

Missing and undeclared fields, unsupported variants, malformed types, unsupported
schema/address and the UTF-8 size bound remain raw-input failures. JSON formatting,
member order and Set ordering/repetition are not no-change gates. Ordered vectors
still carry ordered meaning. Numerical/semantic constraints belong to actual
owning preparation constructors, not raw serialization or repeated certificates.

## First Create and reuse

Registration uses the actual managed call, fixed physical target and current
independent planning rows. Reuse resolves the existing stored record without
comparing its full body to a newly prepared copy or overwriting that identity.
The returned record is observed inert data, not a grant or current semantic
selection; later preparation loads current rows through their selected addresses.
Compatible presentation and historical estimate differences alone are not storage
conflicts. New registration carries actual current facts, not a historical-copy
oracle. Actual owner/state/source admission remains at preparation, never inferred
from equality with a saved record.

Create success alone does not establish committed publication under the admitted
ComponentRecordStorage contract. The immediate selected read therefore remains;
it resolves raw data rather than certifying a complete expected copy. Failed or
uncertain Create, missing/failed observation, malformed observed data or a crossed
selected address are not published as successful observations. A separately
requested later call may observe committed data; no automatic retry machinery
or replacement write is added. Compatible observed diagnostics are not an
indeterminate transaction.
