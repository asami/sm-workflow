# SplitPhase deterministic scope application

This is the pure calculation contract for applying one assigned semantic scope
reply to an already constructed complete projection requirement. It is not
native issue/completion admission, a public operation or a persistence protocol.
Executable specification: `SplitPhaseScopeProjectionComputationSpec`.

## Input

Consume the constructed `ProjectionRequired`, exact first checkpoint and
privately admitted assigned scope reply. The checkpoint must equal the complete
snapshot projected from that constructed requirement. The assigned request must
equal the request selected from that checkpoint, including original transfer
bodies, source closure, context/checkpoint and host result reference. Do not
reconstruct executable candidates from decoded JSON or matching references.

## Whole-frontier calculation

- Retain every original candidate in its original order, with exact cuts,
  child ranges, duration estimates and allocated identities.
- Compute effective producing/receiving item ranges and candidate owner mappings
  for every original transfer. Unknown scopes are not invented.
- Preserve existing Built boundary documents and local work exactly. Retain
  effective narrowed annotations separately; do not rewrite already published
  documents just to reflect narrower ranges.
- Preserve existing repository and numbering Decisions, even if other candidates
  become representable. Do not choose an easy candidate from a held frontier.
- For previously semantic candidates, one shared owner makes the original
  transfer explicit local work. Distinct single owners produce a cross-child
  handoff through the existing proposal/boundary constructors. Preserve original
  kind, input, action, output, invalidation reason, authority, closure, validation
  policy and dependency obligations.
- A known range still spanning several owners produces a typed Human
  representability requirement with exact effective ranges/owners and the
  original candidate. It is not `SemanticRequired` work to send back to AI.
- Only an entirely Built frontier produces a constructed `Projected` value
  usable by existing admissibility and objective calculations. No unresolved
  candidate or Decision can be dropped before ranking.

`DecisionNeeded` retains the full original requirement and admitted reply, with
no partial scopes or invented Human decision.

## Execution boundary

Pure calculated outputs establish no Workflow authority, storage publication,
native transition, Human approval, document application or Terminal. Public
advance must later consume a separately admitted actual completed-native source,
retain this calculation in a separate managed stage and verify canonical
readback. The first checkpoint/index remains immutable. Tests of this processor
do not prove that still-required managed/public continuation.
