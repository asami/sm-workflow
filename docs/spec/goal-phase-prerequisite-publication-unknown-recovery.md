# GoalPhase UNKNOWN prerequisite continuation

## Historical dependency uncertainty and primary failure

An accepted dependency UNKNOWN artifact Direction remains immutable history when
the next applicable primary publication genuinely terminates nonzero. The distinct
primary-continuation v2 target preserves that original UNKNOWN request/result,
its exact Human Direction and original guard, plus the actual primary failure and
unchanged primary candidate. Native traversal authenticates adjacent source and
operation facts after that Direction; it does not require the original candidate
record to be the later frontier.

A changed dependency source needs fresh source-bound artifact authority. Its v7
source Direction may be source-only or explicitly approve the concrete ordered
source/artifact/one-primary plan with
`AdoptDependencySourceRevisionAndContinuePublicationWithUnknownEffects`. The
combined answer is admitted once under the existing dependency-source purpose.
Source capture, artifact adoption and primary authorization remain separate
ordinary Advances and retained outcomes. Each derived operation fact has its own
actual native result identity and identifies the authenticated source directive
through inheritedFrom. No extra Human evidence is manufactured. Source-only
authority leaves the later specific decisions public, and the old UNKNOWN
artifact answer never silently covers changed source bytes.

Only exact source/program/policy/primary/failure bindings inherit the concrete
combined plan. A changed program can require a new specific operation decision;
invalid source guards refuse. A later genuine primary failure requires new
specific authority. A primary UNKNOWN, termination-unconfirmed result, admission
rejection or incomplete reservation offers no dependency UNKNOWN recovery choice:
the v2 PrimaryUncertain phase is collect-only with Defer. A retained genuine
NotExecuted preparation token may continue under its existing one-start authority
after proving its complete nonstart prefix. Neither observation nor preparation
is publication success or validation evidence.

The old dependency UNKNOWN v1 target, optional absent Direction.choice encoding,
writer observations and qualified successor rules retain their meanings. In
particular, terminal primary failure does not become eligible for the old
UNKNOWN-only ensureQualifiedSuccessorC route. Version-2 terminal-failure
qualifications share the existing immutable publication store and passive
collectors while using a distinct internal typed permit.

This is the distinct `sm-workflow.goal-phase-prerequisite-publication-unknown-recovery.v1`

Call `GoalPhaseService.describeGoalPhasePrerequisitePublicationRecovery` with

remain unknown: a missing terminal receipt proves neither termination nor
success, and a current File/Git guard identifies current source bytes only.
No public API can retroactively manufacture the missing historical proof.

`choicesFor(target)` offers these distinct Human decisions:

- `AcceptExistingArtifactsWithUnknownEffects`: accept the uncertainty of the old
  effects and skip only this exact prerequisite publication. Ordinary consumer
  checks still run against existing artifacts; missing or stale APIs may
  truthfully fail and produce ordinary FIX work. This creates no publication
  success, receipt, result or attempt.
- `AuthorizeNewPublicationWithUnknownEffects`: accept possible duplicate,
  concurrent or partial old publication effects and authorize one new attempt
  through ordinary Advance. This is Human authority, not writer-exit or source
  qualification evidence.
- `Defer`: append no Direction, change no history and execute nothing.
