## R1 — Actual assignment, candidate, reviewer and disposition

Goal scope selects instance/source frontier, Step/Phase kind, Step/generation,
Plan reference, base/candidate, check reference and changed paths. Repository
scope selects instance/validated frontier, native parents/index/path coverage,
validation mode and selected check outcomes. Results select actual handle/run/
slot, reference/type/worker and semantic verdict. Typed producers emit these
fields directly; they no longer manufacture a complete WorkOrder/Result transport
and reparse it. Full Plan/policy/diff/log/explanation copies are not certificates.
E1/E2/E4 cover current selected data, unused fields and actual foreign targets.

## R2 — Consume only actionable semantic repair input

Goal repair consumes directive summary/findings. Repository repair consumes
finding identity/paths/rationale. Other outcomes ignore unused directives.
Projectors read actual field types, not enum/coverage/accepted-findings predicates,
array uniqueness/counts, OID/path validity, result-handle pairing or check-selection
coverage. Native review completion/controller owns those actual business semantics.
Reader alone compares independently issued review with the actual target/worker/
reference/purpose/issuer/occurrence. Without that boundary another candidate or
reviewer could reuse independent evidence; it is not an unchanged-plan proof.
E3 preserves actual repair meaning under the attested result reference.

## R3 — Current-only producer, codec and reader

Only v7 selected review/authority/Human fields are supported. The v1–v6 reader
branches, legacy body adapters, expiry conversion, exact-key shape and arbitrary
complete-wire size gates are removed. Unknown unused fields are discarded, never
grants or routes; consumed missing/mistyped fields still fail. E5's compatibility
matrix is retired. E6 retains the existing large-diagnostic normal example without
saving a duplicate body. Other WorkRequest/internal DTO migrations remain part of
the same connected Step, not a promised permanent fallback.

Historical records are untouched, not renewed or silently rewritten. Unsupported
old in-flight executions restart NEW with independently issued current evidence.
Actual retained records requiring continued use need explicit migration.

## R4 — No duplicate revision/model certificates

completion owns actual pending state, type and CAS; the host does not reprove
slot/type/model relationships before that owner. E8 exercises current unused
metadata tolerance and real foreign slots/workers without legacy transport.
