# Native human question current-call publication

## Scope and execution

The user-directed limited recovery continues in the parent, without spawning
agents or changing shared skills. SBT still uses the shared serial wrapper,
fresh permission metadata and ordinary caches. This does not bypass platform
permissions, actor provenance, storage grants or current-call lease admission.
No acceptance, release, commit or push is claimed.

## Implemented boundary

`GoalPhaseManagedNativeHumanQuestion.advanceForCallC` derives the question from
the actual retained accepted review, issued typed candidate, current Workflow
instance and managed host selection. It accepts neither a caller-provided
ClosureAuthority intent nor an arbitrary instance/provider/storage target.
Participant admission checks the actual current execution context independently
of selection data. Publication uses the existing native Decision binding through
the Subsystem-owned shared pool and DataStoreSpace route.

The previous read-only review guard ends before native suspension publication.
The native question is a distinct adjacent revision-four suspension. Recovery
reconstructs only a validated read-only history prefix, derives the same question
from retained review evidence, and checks the complete canonical successor.
It never persists that prefix or downgrades current history. Equal retry keeps
the immutable wire; conflicting choices and stale advancement are refused.
Question presentation does not grant Git or other command authority.

## Executable evidence and limits

The new integration scenario uses actual managed Start, review issuance and
review completion, shared SQLite pool shutdown/reopen, then current-call native
publication and recovery. It checks missing review, copied authentication,
foreign collection, changed choices, an escaped call and a later writer. Pool
and lease observations confirm one managed pool and zero remaining leases.

Selection installation and the invocation probe are explicitly test-only. The
probe calls the private adapter and deliberately stops the enclosing request
before another review issue. This proves the adapter on an actual managed call,
not a production public native endpoint or automatically enabled follow-up.
Human issuer/verifier, native answer completion, full CML lifecycle execution
and CLI/server/MCP activation remain open.
