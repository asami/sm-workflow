## Contract and affected consumers

The intended production path first establishes a standalone immutable initial
candidate catalog record; it neither advances Workflow nor installs data at
startup. Candidate refs must match the typed request's program/planning digests.
RepairSuccessor is rejected, not silently treated as initial registration.
The exact association and artifact collections must be distinct and outside
Workflow instance/Continuation infrastructure. The resolved artifact declaration
restricts the destination but is not a write grant.

The real owning dispatch obtains the captured opaque fixed-identity Create-only
capability before reference materialization. It reads the actual closed
submission registration, requires an identical Workflow handle, independently
admits the submitting participant from actual ingress provenance, re-admits
retained Start using the current host selection and validates the original
registration against that retained witness. Stored claims alone do not grant
authenticated origin, human consent, current progression or writes.

Existing different/malformed selections fail before Blob reads. Initial or
equal retry requires both actual bounded payload reads through the owning
builtin Blob service, using the existing exact metadata/size/content verifier.
Bindings are restored. The record is then observed again, Created only on
verified absence, and compared after committed readback. Return the decoded
retained pair, never preparation bytes. Changed selection/version cannot overwrite
the same key. Initial read failure is not absence. A failed/throwing Create or
post-Create readback is transaction-indeterminate; recover the same identity
without replacement, deletion, compensation or automatic execution retry.

Storage resources remain the Subsystem's common physical provider/lease and
Blob service. No direct SQLite, raw provider escape, private pool, second
transaction engine, save/upsert or event-cursor trick is added. Component
assembly/configuration reading remains free of record installation effects.
