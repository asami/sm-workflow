# GitHub development-work handoff

Date: 2026-10-10
Status: integration direction

Textus Development Center may select durable GitHub Issue/Pull Request work discovered by continuous AI review and form a bounded development handoff for Codex/sm-workflow.

The initial integration may be manual: Development Center generates the handoff and a developer pastes it into Codex Console.

The handoff should preserve the external GitHub work identity, repository, goal, relevant finding/evidence, acceptance criteria and phase/specification references. It should not duplicate the repository or create a second development-work authority.

Once work begins, normal sm-workflow semantics remain authoritative for implementation/review/fix/admission. A later automated path may receive the same logical Development Work Request through Textus Orchestrator.

Continuous reviewers such as Dots are upstream finding sources, not sm-workflow authorities and not automatic permission to modify code.
