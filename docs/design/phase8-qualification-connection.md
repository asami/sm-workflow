Checks use the existing `GoalPhaseNativeValidation.Check` codec: unique

At most sixteen scopes and sixteen checks per scope are
admitted. The complete configured list is required; selection cannot omit a
check. Identities and ordinals must not collide with the captured original
checks. This is a check inventory, not a program registration or effect grant.

The new public contracts are
